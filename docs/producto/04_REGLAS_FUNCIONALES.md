# Reglas funcionales

## Publicacion

- [ ] solo proyectos `published` aparecen en el listado publico
- [ ] un proyecto `draft` nunca aparece publicamente
- [ ] al despublicar vuelve a `draft`

## Preview privada

- [ ] un proyecto `draft` si puede verse por preview privada
- [ ] la preview debe poder compartirse por URL privada
- [ ] la preview no debe indexarse
- [ ] la preview puede desactivarse

## Eliminacion

- [ ] si se elimina un proyecto, su contenido deja de formar parte del sistema visible

## SEO y presentacion minima

- [ ] `title` por pagina publica
- [ ] `meta description` basada en `description`
- [ ] URL limpia por `slug`
- [ ] `alt` obligatorio en imagenes visibles
- [ ] no indexar previews privadas

Extra recomendado:

- [ ] Open Graph por proyecto

## Regla editorial principal

- [ ] el editor debe permitir libertad
- [ ] el modelo del contenido debe permitir intencion narrativa
- [ ] el sitio debe respetar el orden exacto de las secciones
- [ ] el orden de secciones es parte central del producto
