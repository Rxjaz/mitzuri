# Alcance v1

## Decisiones de producto ya definidas

- [x] Habra una sola usuaria administradora.
- [x] No habra registro publico.
- [x] Solo habra `login` privado.
- [x] El sitio tendra listado publico de proyectos.
- [x] Cada proyecto tendra pagina publica individual.
- [x] Existira preview privada por URL.
- [x] El contenido se construira por bloques ordenados.
- [x] Tipos de bloque v1: `heading`, `text`, `image`, `beforeAfter`, `gallery`.
- [x] El frontend se divide en area publica y admin.
- [x] Ruta publica `/`.
- [x] Ruta privada `/admin`.

## Objetivo real de la v1

La v1 es exitosa cuando la disenadora puede:

- [ ] iniciar sesion
- [ ] crear un proyecto `draft`
- [ ] editar datos base
- [ ] agregar, editar, eliminar y reordenar secciones
- [ ] asociar imagenes
- [ ] abrir preview privada
- [ ] publicar
- [ ] ver el proyecto en el sitio publico
- [ ] compartir la URL publica

## Incluido en v1

- [ ] login admin
- [ ] dashboard privado basico
- [ ] CRUD de proyectos
- [ ] CRUD de secciones
- [ ] reordenamiento
- [ ] preview privada
- [ ] publicacion manual
