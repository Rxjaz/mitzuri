# Experiencia publica

## Lo que debe poder ver una visitante

- un home publico con proyectos publicados
- una pagina individual por proyecto
- una narrativa visual construida por bloques
- imagenes bien presentadas
- informacion clara del proyecto

## Lo que no debe poder hacer

- registrarse
- entrar al admin
- ver borradores por defecto

## Pantallas minimas

- [ ] Home publica con listado de proyectos publicados
- [ ] Pagina publica de proyecto por `slug`
- [ ] Preview privada por `token`

## Requisitos de experiencia

- [ ] render dinamico de bloques segun `type`
- [ ] buen rendimiento de imagenes
- [ ] diseno sobrio y profesional
- [ ] buen comportamiento en desktop y mobile
- [ ] la preview debe verse casi igual que la pagina publica final

## Narrativa esperada

Cada proyecto deberia poder contar algo como:

1. Contexto.
2. Problema o reto.
3. Proceso o exploracion.
4. Solucion visual.
5. Resultado o cierre.
