# Vision del producto

`Mitzuri` sera una plataforma web con dos caras:

- sitio publico para mostrar proyectos
- CMS privado para que una sola administradora gestione el contenido

## A quien sirve

La usuaria principal es una sola disenadora administradora.

No hay:

- registro publico
- multiples roles
- area de usuario para visitantes

## Para que existe

El producto debe ayudar a la disenadora a:

- mostrar su trabajo de forma profesional
- construir historias visuales con intencion
- compartir previews privadas antes de publicar
- operar su portafolio sin depender de desarrollo para cada cambio

## Definicion corta de v1

> Una herramienta que permita a la disenadora crear, publicar y compartir proyectos de forma autonoma.
